## 三方面复核后的选择

1. 基础网络与启动：固定基线的 OpenWrt 25.12.5、Linux 6.12.94、feeds、设备补丁、
   MT76 驱动及 OpenClash。保留所有既有基础包，不修改 GPT、引导、factory、
   默认网口、无线驱动、CPU 调度或加速设置。基础 SSH、LuCI、DHCP 和 IPv6 均保留。
2. 游戏与代理：只增加 SQM 中文页面及原生依赖，出厂禁用且上下行速率为 0，
   防止猜错上传带宽或 WAN 接口而限速。提供 CAKE / piece_of_cake.qos；
   保留 SQM 声明的 nft 兼容 iptables 依赖及 IPv6 对应组件，不启用 legacy 防火墙。
   不增加 UPnP、其他 DNS/代理应用、自动测速、模拟浏览器保活或定时重启。
3. 管理与升级：保留 HTTP/HTTPS，取消 HTTP 强制跳转。HTTP 密码和会话明文传输，
   仅适合可信的本地网络；HTTPS 仍使用设备本机生成的证书，浏览器不会自动信任它。
   保留 WAN 输入拒绝策略及 APK 签名、TLS、依赖和真实内核 ABI 检查。
   升级范围、分区容量检查和同次签名 APK 交付沿用基线，不增加刷写脚本。

新增的顶层选择为 `luci-app-sqm`、`luci-i18n-sqm-zh-cn`、`sqm-scripts`、
`tc-tiny`、`kmod-sched-cake`、`kmod-ifb`、`iptables-nft`、`ip6tables-nft`、
`iptables-mod-ipopt`，其余是原生依赖闭包。固定 packages feed 中 SQM 为 1.7.2-r1，
源提交 `20ba92639546075d8e39346dcb88a3cdfe8ee903`。
不改 OpenClash 默认停用、小闪存关闭及手动安装 ARM64 核心的流程。
软件包完整清单和最终大小以本次构建实际输出为准。

## 验证增强及其边界

交付前直接从唯一的 sysupgrade BIN 提取 SquashFS，用同次构建的原生 unsquashfs4
严格解包。非 root 执行，仅排除 `/dev/console` 设备节点；其他提取错误终止验收。
不执行固件内程序。检查真实镜像数据库、清单、内核模块、中文页面、默认配置、
五个基础服务的启动链接、核心可执行路径及 ELF 加载器/动态库依赖闭包。
日志无论成功或失败均收集；不通过忽略解包错误或缺依赖来发布产物。

这些静态检查不能证明首次启动、eMMC 挂载或所有服务实际运行正常。
新候选版须重新测试有线管理、DHCP、WAN、双频 Wi-Fi、重启及配置保留，
再手动安装核心测试 OpenClash。至少观察 24～48 小时。保留已成功恢复的旧镜像，
不要把 GPT、BL2、FIP 或 U-Boot 文件当作普通固件刷写。

## 游戏验证与 SQM 使用

用户反馈直连正常、OpenClash 开启后延迟上升，保持其后台页面打开时改善。
源码可见状态页面轮询及周期外网检测，但尚无对照证明它们与延迟改善存在因果关系。
基线内核没有启用 CPU_IDLE；不据此加入强制高性能或周期发流量脚本。

先保持 SQM 关闭，比较同一时段同一游戏、同一节点：OpenClash 关闭、规则模式启用、
普通 LuCI 页面打开、OpenClash 页面打开。QQ 飞车端游优先测试直连规则；
Steam 按具体游戏区分登录/下载和游戏服务器，不能简单把所有 Steam 流量强制走代理。
游戏 UDP 是否走代理应以连接记录为准，不公开上传含节点、订阅或账号的日志。

只有下载/上传占满时延迟明显增加，才考虑启用 SQM：用有线测量稳定上下行，
在“网络 → SQM QoS”中填写各自约 90%～95% 的实测速率，单位 kbit/s，不能猜上传速率。
DHCP WAN 通常为 eth1；PPPoE 应确认实际 pppoe-wan 等三层设备。
选择 cake 与 piece_of_cake.qos，链路开销按实际接入设置，不预填未知 PPPoE/VLAN 开销。
一次仅修改一项，满载对比延迟、吞吐、CPU 和丢包；无收益时停用 SQM 并复测。
SQM 缓解本地出口拥塞，不能修复代理节点绕路、运营商线路或游戏服务器的延迟。

## 构建与回退

独立审核分支为 `codex/rax3000m-emmc-sqm`，新工作流为
`rax3000m-emmc-openclash-sqm.yml`，原工作流与默认分支不改。
镜像名加入 `sqm` 区分候选版，仍为目标设备的原生 `squashfs-sysupgrade.bin`。
刷机入口和备份说明见 UPGRADE.md；旧版实机成功不等于新候选版已经验证。
保留旧配置也会在新镜像首次脚本执行时关闭 OpenClash、所有 SQM 队列及无线，
取消 HTTP 强制跳转；不承诺保留启用状态。旧 SQM 接口、速率及代理规则可能仍保留，
应逐项核对，不承诺跨版本配置直接兼容。SQM 的速率 0 表示不对该方向整形，
不是自动测速，也不是断网。
本任务不连接路由器、不执行备份、恢复、重置或刷写。
